Odisha state boundary

The polygon in odisha-boundary.csv is the Odisha feature extracted from the
simplified India ADM1 GeoJSON release:
https://github.com/wmgeolab/geoBoundaries/raw/9469f09/releaseData/gbOpen/IND/ADM1/geoBoundaries-IND-ADM1_simplified.geojson

Boundary source: DataMeet India community, Election Commission of India,
via geoBoundaries. Boundary year represented: 2011.
License: Creative Commons Attribution 2.5 India (CC BY 2.5 IN).

The geometry is used only for backend point-in-polygon validation. It does not
represent a booking search radius or road-distance service area.
